WEB PROGRAMMING · WEEK 03

從本機開發到公開部署

本機服務、反向代理和 HTTPS 是不同環節；逐一確認，才知道作品是否真的能被外部使用者存取。

Browser→ IIS / HTTPS→ Uvicorn→ FastAPI 靜態檔案

01 · LEARNING GOALS

完成本週後，你可以

  • 說明 FastAPI 應用程式如何透過 Uvicorn 提供 HTTP 服務。
  • 用 StaticFiles 把 HTML、CSS、JavaScript 等前端檔案提供給瀏覽器。
  • 解釋 IIS URL Rewrite / ARR 如何把 HTTPS 請求反向代理到內部服務。
  • 區分本機測試成功、網路可達和公開 HTTPS 部署驗收成功。

02 · REQUEST PATH

每一層負責不同工作

元件工作如何確認
瀏覽器 送出 HTTP/HTTPS 請求，接收 HTML、CSS、JavaScript 或 API 回應 檢查網址、Network status 和資源載入。
IIS + URL Rewrite / ARR 接收外部連線，依規則把請求轉送至後端服務 依授課環境設定檢查子路徑和代理規則。
Uvicorn ASGI server，負責接收連線並呼叫 ASGI 應用程式 確認程序正在執行、監聽位址和連接埠正確。
FastAPI / StaticFiles 提供應用程式路由或前端靜態檔案 檢查首頁、CSS、JavaScript 和 API 路徑。
ASGI 是介面規格，不是部署保證

ASGI 定義 Python 非同步 Web 應用程式與 server 之間如何溝通；Uvicorn 是 ASGI server 的一種。使用 ASGI 並不代表程式一定更快，實際表現仍取決於應用程式、工作負載和部署設定。

03 · LOCAL SERVICE

先在本機確認靜態網站正常

本專案由 FastAPI 將 public/ 目錄掛載為靜態網站；html=True 會讓根路徑提供 index.html。

app.mount(
    "/",
    StaticFiles(directory="public", html=True),
    name="public",
)
uvicorn server:app --reload --host 127.0.0.1 --port 7777

server:app 表示從 server.py 載入 app 物件； --reload 適合本機開發時自動重載。 127.0.0.1 只接受本機連線，適合先做本機檢查，不代表 IIS 公開代理已設定完成。

04 · REVERSE PROXY & HTTPS

IIS 代理外部請求到 Uvicorn

使用者瀏覽器
    │ HTTPS :443
    ▼
IIS：URL Rewrite / ARR
    │ 內部轉送（依授課環境設定）
    ▼
Uvicorn :7777 → FastAPI

IIS 可在外部接收 HTTPS，並依規則轉送到內部 Uvicorn。這類 SSL termination 代表瀏覽器到 IIS 的連線使用 HTTPS；內部轉送是否加密，則需依實際網路環境和伺服器設定確認， 不能單靠網址有鎖頭就推定整條路徑都加密。

請只在授課者授權的環境設定外部連線

綁定所有網路介面或開放防火牆連接埠會讓其他裝置可能連到開發服務。依老師指定的 IP、連接埠和規則操作，不要自行把開發伺服器公開到網路。

05 · DEPLOYMENT CHECKLIST

分階段驗收，不只看首頁

  1. 本機服務啟動後，確認首頁和靜態資源能由瀏覽器載入。
  2. 若要部署在子路徑，確認 CSS、JavaScript 和資料網址使用相容的相對路徑。
  3. 請老師確認 IIS URL Rewrite、ARR、路由子路徑和網路設定。
  4. 使用老師提供的 HTTPS 網址測試首頁及重要資源，並查看 Network 中的錯誤。
  5. 只有完成外部網址的實際測試，才能記錄為公開部署驗收完成。

本專案目前已確認本機 FastAPI 可提供網站；IIS 子路徑和公開網址仍需依老師環境驗收， 因此這份教材不把本機測試寫成公開部署成功。

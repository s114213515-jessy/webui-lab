WEB PROGRAMMING · WEEK 02

Web UI and HTML

先看懂網頁有哪些區域、各區域要做什麼，再用合適的 HTML 標籤把內容組織起來。

使用者需求→ 頁面區塊→ HTML 結構→ 瀏覽器呈現

01 · LEARNING GOALS

完成本週後，你可以

  • 辨認頁面中的側邊欄、主要內容、標題和輸入表單。
  • 挑選適合用途的語意化 HTML 標籤，而不是所有東西都用 div。
  • 用目標使用者、核心功能和 MVP 說明網站要解決什麼問題。
  • 讓 HTML 結構清楚，之後較容易加上 CSS 和 JavaScript。

02 · PAGE STRUCTURE

先把頁面想成幾個區域

頁面頂部header
→
輔助／導覽aside / nav
→
主要內容main
→
頁面底部footer

HTML 負責描述內容和結構；CSS 之後再負責顏色、間距和版面。先把區域分清楚， 看程式時就比較容易知道某段內容屬於哪裡。

03 · SEMANTIC HTML

標籤名稱也在說明內容的用途

標籤常見用途儀表板例子
header頁面或區塊的頂部資訊網站名稱和登入按鈕
nav主要導覽連結側邊功能選單、課程連結
main頁面主要內容摘要卡片和目前頁面內容
aside補充或相鄰內容側邊欄
section同一主題的內容區塊儀表板摘要區
form輸入與提交資料搜尋或登入欄位
那 div 和 span 呢？

div 和 span 是一般容器，本身不表示內容的角色。沒有更合適的語意標籤時可以使用，但不需要把整個網站都寫成 div。

語意化結構能幫助開發者閱讀，也讓瀏覽器、搜尋引擎和螢幕閱讀器更容易理解頁面。 例如側邊欄如果主要用來切換頁面，可以在其中使用 nav。

04 · PROJECT MILESTONE

動手寫出網站規劃

Problem

使用者遇到什麼問題？為什麼需要這個網站？

Target Users

誰會使用？他們需要完成什麼事情？

Core Features

最重要的兩、三個功能是什麼？

Data & API

需要哪些資料？目前是範例資料，還是需要串接 API？

Security / Privacy

資料中有沒有個資、密碼或不應公開的內容？

MVP

時間有限時，最少完成哪些功能，作品才有基本用途？

05 · CHECK YOUR PAGE

用自己的首頁練習

  1. 在首頁找出 header、aside、nav、main 和 footer。
  2. 檢查標題層級是否合理：主要標題用一個 h1，內容區塊再用 h2。
  3. 想想哪些地方是主要內容、哪些只是輔助資訊，為它們選擇適合的標籤。
  4. 用 Problem、Target Users、Core Features 和 MVP 說明自己的網站。

01 · LEARNING GOALS

完成本週後，你可以

  • 用 CSS Box Model 理解元素的大小、內距、邊框和外距。
  • 判斷頁面區塊適合使用 Grid 還是 Flexbox。
  • 用 CSS 變數集中管理顏色、間距和主題。
  • 從手機版開始設計，並在不同視窗寬度檢查版面。

02 · GRID OR FLEX?

先看版面是一維還是二維

工具適合情境教務儀表板例子
Grid 同時安排欄和列，處理二維版面 側邊欄加主要內容；多欄摘要卡片
Flexbox 沿單一方向排列和對齊 頂部按鈕列、導覽連結、卡片內操作列
gap 控制 Grid 或 Flex 項目之間的距離 統一欄位與卡片間距
簡單判斷方式

先決定整個頁面的大區塊，再用 Grid 排主結構；某一區內的按鈕或連結若只沿一排排列，通常 Flexbox 就很適合。

03 · BOX MODEL

每個元素都可以想成一個盒子

內容到邊框的空間padding
→
元素外側的線border
→
盒子與其他元素的距離margin
*,
*::before,
*::after {
  box-sizing: border-box;
}

使用 border-box 後，設定的寬度會包含 padding 和 border， 比較容易預測卡片實際佔用的空間。

04 · CSS VARIABLES

把常用樣式集中管理

:root {
  --color-page: #f4f6fb;
  --color-surface: #ffffff;
  --color-text: #182230;
  --color-accent: #3559c7;
  --space-page: 1rem;
}

使用 CSS 變數後，如果要調整網站主色或背景，就能集中修改，不必到處尋找相同的顏色值。 深色模式也可以覆寫這些變數，讓多個元件一起切換。

05 · MOBILE FIRST RWD

先讓小螢幕好用，再增加空間

手機螢幕較窄，先安排單欄內容和容易點擊的操作；寬度增加後，再用 media query 加入側邊欄或多欄卡片。不要只為了符合某一台裝置設定固定寬度。 

/* 預設先支援窄螢幕 */
.page-layout {
  display: grid;
  grid-template-columns: minmax(0, 1fr);
}

/* 空間足夠時才加入側邊欄 */
@media (min-width: 48rem) {
  .page-layout {
    grid-template-columns: 14rem minmax(0, 1fr);
  }
}
  • 內容不要超出視窗，卡片可以自動換行。
  • 避免按鈕太小或彼此太靠近，影響觸控操作。
  • 縮放瀏覽器寬度，檢查導覽、表格和卡片是否仍可閱讀。

06 · RESPONSIVE CHECK

檢查自己的儀表板

  1. 在瀏覽器開啟開發者工具的裝置工具列，查看手機和桌機尺寸。
  2. 確認手機版側邊欄、摘要卡片和操作按鈕沒有互相擠壓。
  3. 找出哪裡用了 Grid、Flexbox、CSS 變數和 media query。
  4. 若有跑版，先檢查固定寬度、過大的間距和內容溢出，再調整斷點。
